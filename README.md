## Featured Projects

### tenderX — Online Tender Management

A 5-service containerised platform for running tenders end to end: role-based access, MFA-backed auth, and a full audit trail.

<a href="https://github.com/Suryatej73/online_tender_management">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Suryatej73&repo=online_tender_management&theme=nord&title_color=7dd3fc&text_color=c9d1d9&icon_color=7dd3fc&border_color=7dd3fc&bg_color=0d1117&hide_border=false" alt="tenderX" />
</a>

| Layer | Technology |
| :--- | :--- |
| Frontend | React 18, Vite |
| API | Django 4.2, Django REST Framework — 27 endpoints across 25 views |
| Auth | JWT access/refresh, TOTP MFA via `pyotp`, RBAC with 6 roles |
| Async | Celery 5 worker, Redis 7 broker |
| Database | PostgreSQL 15 |
| Ops | Docker Compose (5 services), 3-job GitHub Actions CI |
| Testing | 9 unit tests covering the auth surface |

Auditing is first-class: login attempts, user activity, and sessions are all persisted as models. 3 of 12 roadmap modules are shipped.
